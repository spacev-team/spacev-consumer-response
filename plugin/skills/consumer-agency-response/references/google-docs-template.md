# Google Docs 고정 템플릿

## 적용 범위

[document-routing.md](document-routing.md)를 먼저 따른다. **이 파일의 마스터 열람·복사 절차는 `copy_master` 전용이다.** 사용자가 작업 문서를 지정해 직접 편집하도록 요청한 `edit_existing`은 그 문서를 그대로 읽고 수정하며, 마스터를 추가로 열거나 복사하지 않는다.

## 새 답변서용 영구 마스터

- 문서 ID: `1slSv_nu58ITcUz07pm-O1EVcSf1n7v7_viQ93cqaxHo`
- 기준 URL: `https://docs.google.com/document/d/1slSv_nu58ITcUz07pm-O1EVcSf1n7v7_viQ93cqaxHo`
- 문서 제목: `[답변서] 고정 양식`

새 답변서는 이 빈 마스터를 고정 ID로 읽고 네이티브 복사한 사본에 작성한다. 제목 검색으로 대체 양식을 찾거나 과거 사건 답변서를 새 문서의 마스터로 사용하지 않는다. 영구 마스터에는 사건 내용을 쓰지 않는다.

`copy_master`의 복제 전후에 아래 구조를 확인한다. `edit_existing`은 지정 문서의 같은 양식 요소를 편집 전후에 보존한다.

- 단일 탭 문서
- A4 페이지, Arial 11pt 기본 스타일
- 우측 상단 SpaceV 로고가 `positionedObject`로 존재
  - 크기 약 `64.33pt × 19.87pt`
  - `BEHIND_TEXT`
  - 첫 문단이 로고 positioned object를 참조
- `답 변 서` 제목
  - 가운데 정렬
  - Bold
  - 29pt
- 수신인 영역
  - 1행 × 1열 표
  - 열 너비 약 `447pt`
  - 기본 텍스트 `수신인 ㅣ 담당자님`
- 제목 기본 문구: `제목 : 임대목적물 이용 관련 민원 접수 건에 대한 회신`
- `1. 계약 내용`

  - 열 너비 약 `91.5pt / 362.25pt`

  - 2행: `이용상품` / 빈 값

## 필드 채우기·교체 규칙

선택한 경로의 작업 문서에서 **기존 구조를 재작성하지 않고 필드와 본문을 채우거나 교체한다.** 기존 문서의 값이 이미 채워져 있어도 직접 편집할 수 있다.

1. 문서번호: `문서번호 ㅣ` 뒤의 값 영역에 확인된 문서번호를 넣는다. 번호가 없으면 임의로 발급하거나 과거 사건 번호를 재사용하지 않고 필요한 확인 사항으로 남긴다.
2. 수신인: `담당자님` 앞에 기관명 또는 확인된 담당자명을 넣는다. 담당자명이 없으면 `한국소비자원 담당자님`처럼 기관명 + 담당자님으로 작성한다.
3. 제목: 사건 쟁점을 반영해 제목 문구만 교체하되 기존 제목 스타일을 유지한다.
4. 계약기간: 계약 표의 우측 첫 번째 값 셀을 `contract_period` 원문으로 채우거나 교체한다.
5. 이용상품: 계약 표의 우측 두 번째 값 셀을 `product_name` 원문으로 채우거나 교체한다.
6. 2항 본문: `2. 민원 내용 및 확인 결과` 바로 아래에 현재 사건의 2항 문단만 삽입한다.
7. 3항 본문: `3. 민원 관련 당사 입장 및 조치` 바로 아래에 현재 사건의 3항 문단만 삽입한다.
8. 발신일자/담당자: 하단의 해당 값만 확인된 정보로 채우거나 교체한다. 연락처·이메일·발신인은 요청된 변경 범위만 반영하고 가로선·필드·링크 서식은 유지한다.

본문 삽입 시 새로 추가된 일반 문장은 템플릿의 기본 본문 스타일(Arial 11pt, 검정, Bold 아님)을 사용한다. 섹션 제목의 Bold/크기/간격은 변경하지 않는다.

## 원본과 결과물

- `edit_existing`: 사용자가 지정한 작업 문서 ID와 결과 문서 ID가 같다. 이미 준비된 작업 문서를 다시 복사할 필요가 없다.
- `copy_master`: 이번에 생성된 사본을 편집하고 반환한다. 마스터와 사본 ID가 같으면 쓰기를 진행하지 않는다.
- 영구 마스터와 사용자 작업 문서를 구분한다. ‘원본 보호’는 사건 작성 과정에서 영구 마스터를 보호한다는 뜻이며, 사용자가 직접 편집하도록 지정한 작업 문서를 수정하지 말라는 뜻이 아니다.
- Google Docs 요청을 새 빈 문서 재구성·Word/DOCX·Markdown·채팅 답변서로 대체하지 않는다. 사용자가 명시적으로 텍스트만 요청한 경우에는 `text_only`를 따른다.
- 복사 기능이 필요한 경로와 중단 안내는 [document-routing.md](document-routing.md), 편집 전후의 양식 검수는 [native-copy-fidelity-gate.md](native-copy-fidelity-gate.md)를 따른다.

## 최종 완성 체크

- 수신인, 제목, 계약기간, 이용상품, 2항·3항, 필요한 발신 필드가 현재 사건에 맞게 채워져 있다.
- 문서번호 등 확인되지 않은 값을 임의로 만들지 않았다.
- SpaceV 로고, 제목 스타일, 고정 표 너비, 하단 가로선과 발신부가 유지된다.
- 요청 범위 밖의 내용은 유지하고, 교체 대상인 과거 사건 사실은 남기지 않았다.
- 링크는 실제 편집한 원본 또는 생성한 사본의 검증된 URL이다.
