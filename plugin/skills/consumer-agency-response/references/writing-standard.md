# 문장 기준

## 기본 톤

담백하고 사실 중심으로 쓴다. 자료에 있는 모든 내용을 넣지 않는다. 소비자기관 담당자가 `무슨 민원인지`, `회사가 무엇을 확인하고 무엇을 했는지`, `현재 무엇을 할 수 있는지`를 빠르게 이해하면 충분하다.

## 관련성 우선

좋은 문장은 사실이 많아서 좋은 것이 아니라 필요한 사실만 있어서 좋다.

- 결제 상세는 계약기간·이용상품 확인용이 기본이다.
- 이용대금 세부 구성은 쟁점 자체가 금액 산정이 아니면 쓰지 않는다.
- 보증금은 민원 쟁점이 아니면 쓰지 않는다.
- 증빙 공백은 그 자체로 쓰지 않는다. 대신 당사가 실제로 요청·확인한 조치를 쓴다.

나쁜 예:
> 제공된 기록에서는 냉장실 조치가 완료되었다는 내용은 확인되지 않습니다.

더 나은 방향:
> 당사는 임대인에게 냉장실 문제에 대한 조치와 환불 협의를 요청하였습니다.

단, 기관이 조치 완료 여부를 직접 묻는 경우에는 확인 상태를 정확히 답한다.

## 중복 금지

같은 사실은 문서 전체에서 한 번만 쓴다.

나쁜 구조:
- 2항: 당사가 8월 21일 임대인에게 환불 협의를 요청함
- 3항: 당사가 8월 21일 임대인에게 환불 협의를 요청함

좋은 구조:
- 2항: 민원인이 문제를 제기하고 퇴실하기까지의 경위
- 3항: 당사가 임대인에게 환불 협의를 요청하고 임대인의 반환 의사를 확인한 내용

표현을 바꿨더라도 같은 사실이면 반복으로 본다.

## 당사의 노력

당사 역할의 한계를 쓰기 전에 **실제로 한 노력**을 보여준다.

예:
> 당사는 민원인의 요청을 확인한 후 임대인에게 이용대금 반환 협의를 요청하였으며, 실제 이용기간과 제기된 불편 사항을 고려하여 일부 반환하는 방향으로 중재하였습니다. 임대인은 이용대금의 50%를 반환하겠다는 의사를 밝혔습니다.

임대인이 전액 반환이 어렵다고 설명한 사유가 자료에 명확하면 필요한 범위에서 붙인다. 명확한 사유가 없으면 추정하지 않는다.

## 협의 중 발언

협의 과정에서 나온 모든 말을 기록하지 않는다.

특히 아래는 최종 해결에 직접 필요하지 않으면 제외한다.

- `민원을 넣지 않으면 전액 반환` 같은 조건부 표현
- `전액 반환도 생각해볼 수 있음` 같은 가정적 표현
- 최종 합의로 이어지지 않은 일시적 제안

현재 확인된 실질적 반환안 또는 실제 이행 상태를 중심으로 쓴다.

## 회사 보상

실제 회사 조치의 성격을 정확히 쓴다.

권장:
> 민원인이 이용 과정에서 겪은 불편을 고려하여, 당사는 계약수수료 40,590원을 현금으로 보상하였습니다.

피함:
> 별도 CS 지원금을 지급했습니다.

금액의 기준과 처리 방식이 확인되는 경우 한 문장 안에서 자연스럽게 설명한다.

## 리스크 표현

전대·등록 권한·법 위반 가능성을 본문에서 세부적으로 확대하지 않는다.

권장:
> 민원인이 제기한 임대 권한 관련 내용에 대해서도 당사는 임대인에게 사실관계 확인을 요청하였습니다.

피함:
> 전대차동의서가 제출되지 않아 무단 전대 여부가 확인되지 않았습니다.

위법 여부를 확정하지 않고, 당사가 확인한 행동만 쓴다.

## 역할의 한계

`당사가 무엇을 했는지 → 왜 직접 강제할 수 없는지` 순서로 쓴다.

> 해당 이용대금은 입주 확인 후 임대인에게 정산된 금액으로, 당사가 임대인의 동의 없이 이를 임의로 회수하여 반환하기는 어렵습니다.

이 문장은 실제 정산이 확인되고 이용대금 환불이 쟁점일 때만 쓴다.

## 문단 길이

- 1~2문장
- 렌더링 결과 3줄 이내
- 한 문단에 한 가지 역할
- `또한`, `아울러`, `다만`을 계속 붙여 길게 만들지 않는다.

## 용어

| 사용하지 않음 | 사용함 |
|---|---|
| 숙소, 객실 | 임대목적물, 계약 대상 공간 |
| 숙박, 숙박비 | 단기임대, 이용대금, 임대료 |
| 예약 | 계약 |
| 체크인, 체크아웃 | 입주, 입주 확인, 퇴실 |
| 게스트, 호스트 | 민원인·임차인, 임대인 |
| 플랫폼 | 단기임대 서비스, 서비스 운영자 |
