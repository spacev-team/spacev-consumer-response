# 좋은 답변서 패턴

사례의 이름·날짜·금액은 복사하지 않는다. 구조만 참고한다.

## 패턴 A - 옵션 오해와 취소

민원인의 기대와 실제 게시 옵션을 비교하고, 임대인이 무엇을 약속했는지 확인한다. 전액환불 합의가 없으면 만들지 않는다. 회사가 별도로 지원한 금액이 있다면 임대인 반환과 분리한다.

**핵심:** 민원 요구액은 결과가 아니다. 객관적 정보와 실제 합의만 쓴다.

## 패턴 B - 청소·통신 문제와 중도퇴실

민원인의 불편과 퇴실 경위를 설명한 뒤, 회사가 임대인에게 환불 협의를 요청한 과정과 임대인의 현재 반환 입장을 쓴다. 회사 자체 보상은 별도 한 문장으로 정리한다.

**핵심:** `우리는 권한이 없다`보다 먼저 `우리가 무엇을 했는지`가 보여야 한다.

## 패턴 C - 시설 문제와 일부 반환 협의

시설 문제 자체를 장황하게 심판하지 않는다. 민원인이 무엇을 요구했고, 회사가 임대인에게 어떤 조치와 반환 협의를 요청했으며, 임대인이 어떤 실질적 안을 제시했는지를 중심으로 쓴다.

**핵심:** 증빙 공백보다 실제 중재 행동이 중요하다.

## 패턴 D - 리스크가 큰 임대 권한 이의

민원인이 임대 권한에 이의를 제기하면 회사가 사실관계 확인을 요청했다는 수준으로 정리한다. 자료 미제출 상태, 불법 여부, 무단 전대 여부를 스스로 판단해 확대하지 않는다.

**핵심:** 확인 행동은 쓰고 법적 결론은 만들지 않는다.

## 827571 회귀 패턴

민원인은 청소 상태, 건조대 이용 방식, 냉장실 문제와 대응 지연을 이유로 중도퇴실 후 이용대금 반환을 요구했다. 회사는 임대인에게 반환 협의를 요청했고 임대인은 일부 반환 의사를 밝혔다. 회사는 민원인이 겪은 불편을 고려해 계약수수료 상당액을 현금 보상했다. 임대 권한 관련 이의도 제기되었다.

**좋은 방향:**
- 1항은 계약기간·이용상품만
- 2항은 민원 내용과 이용/퇴실 경위만
- 3항은 회사의 반환 협의 노력, 임대인의 일부 반환 입장, 회사의 현금 보상, 정산 이후 권한 한계, 임대 권한 관련 사실확인 요청을 중복 없이 정리
- 보증금 정상 반환, 냉장실 조치 완료 증빙 공백, 조건부 전액 반환 발언은 본문에서 제외

**나쁜 방향:**
- 결제 상세 금액 구성을 본문에서 다시 설명
- `수리 완료 기록이 없다`를 중요한 결론처럼 강조
- 조건부 전액 반환 발언을 최종 입장처럼 노출
- 보증금 반환을 민원 해결 조치처럼 강조
- 임대 권한 자료 미확인을 무단 전대나 위법 판단으로 확대
