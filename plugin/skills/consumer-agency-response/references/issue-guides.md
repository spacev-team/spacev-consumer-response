# 쟁점별 확인 기준

현재 민원에 직접 필요한 항목만 사용한다. 확인했다고 해서 전부 답변서에 쓰지 않는다.

## 취소·위약금

- 취소 시점과 적용 기준
- 실제 환불·위약금 처리 상태
- 임대인 조정 의사
- 당사가 조정한 내용

금액 산정이 핵심일 때만 계약 내용 표에 금액 추가를 사용자에게 제안한다.

## 중도퇴실·잔여 이용대금

- 실제 이용 경위와 퇴실 시점
- 환불 요구 내용
- 임대인의 현재 반환 입장과 그 사유가 명확한지
- 당사가 임대인에게 반환 협의를 요청한 내용
- 이미 정산된 금액을 당사가 직접 회수할 수 있는지

## 시설 하자·이용 제한

- 민원인이 제기한 핵심 하자
- 임대인의 조치 또는 답변
- 이용 지속 또는 퇴실 경위
- 당사가 임대인에게 조치·환불 협의를 요청한 내용

`수리 완료 증빙 없음` 자체는 기관이 묻거나 결론에 꼭 필요하지 않으면 본문에 쓰지 않는다.

## 상세페이지 정보 상이

- 실제 게시 정보와 민원인의 주장 차이
- 임대인이 제공을 약속했는지
- 당사가 확인·중재한 내용

## 임대 권한·전대 관련 이의

- 민원인이 해당 문제를 제기했는지
- 당사가 임대인에게 사실관계 확인을 요청했는지

기본적으로 여기까지만 쓴다. `불법`, `무단 전대`, `전대차동의서 미제출` 등의 세부 표현은 공문이 직접 묻거나 객관적으로 확정된 경우가 아니면 사용하지 않는다.

## 보증금

보증금 자체가 민원 쟁점인 경우에만 확인한다.

- 반환·공제 상태
- 공제 사유와 이의 내용
- 당사 중재 내용

정상 반환된 보증금이 현재 민원의 쟁점이 아니면 본문에서 제외한다.

## 추가 계약 항목 제안

기본 표는 계약기간과 이용상품만 사용한다.

- 주소가 핵심: `동일 임대목적물 여부 확인이 중요해서 계약 주소도 넣으면 어떨까요?`
- 금액 산정이 핵심: `반환액 산정이 핵심이어서 결제금액과 환불금액도 넣으면 어떨까요?`
- 계약 시점이 핵심: `취소 규정 적용 시점을 보여주기 위해 계약일자도 넣으면 어떨까요?`

사용자 동의 전에는 추가하지 않는다.
