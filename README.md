공문·결제 상세 정보·계약메모를 검토해 국내 소비자기관 답변서를 작성합니다.

| 요청 | 처리 |
| --- | --- |
| “내가 준 링크를 직접 수정해줘”, “이 문서에 채워줘” | 지정한 같은 Google 문서를 읽고 편집. 복사 기능 불필요 |
