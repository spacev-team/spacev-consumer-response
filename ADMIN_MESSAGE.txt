소비자원 답변서 Plugin v1.5.4 업데이트 반영 확인 요청

이번 버전은 사용자가 지정한 Google 문서를 직접 수정할 때 복사 기능을 요구하지 않도록 실행 경로를 정리했습니다. 새 답변서 생성에는 기존대로 영구 마스터의 네이티브 복사를 사용합니다.

저장소 업데이트 후 해당 Marketplace를 동기화하고, 플러그인 상세에 1.5.4가 표시되는지 확인해 주세요. 직원은 새 대화에서 준비된 문서를 지정해 “내가 준 링크를 직접 수정해줘”라고 요청하면 됩니다.

직접 편집에는 Google Drive 문서 읽기·편집 동작과 해당 원본의 접근권한이 필요합니다. 복사 동작은 새 문서 생성에만 필요하며, 기존 앱 권한·설치 정책은 변경하지 않습니다.
