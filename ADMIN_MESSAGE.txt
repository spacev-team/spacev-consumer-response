사내 소비자원 답변서 Plugin을 GitHub Marketplace 방식으로 배포하려고 합니다.

관리자 설정에서 아래 순서로 최초 1회 Import 부탁드립니다.

1. Workspace settings > Plugins > Add > Import marketplace
2. Source: 제가 전달드리는 GitHub 저장소 URL
3. Path: 비워두기
4. Branch: 비워두기(기본 브랜치 사용)
5. Import marketplace 실행 및 GitHub 권한 승인
6. spacev-consumer-response Plugin의 Installation policy를 Available로 설정
7. Google Drive 사용 가능 여부 확인

Available은 자동 설치가 아니라, 필요한 직원이 사내 Plugins Directory에서 직접 설치하는 방식입니다.
이후 Plugin 업데이트는 GitHub에서 관리하며, ChatGPT에서 매일 자동 동기화됩니다.
급한 업데이트는 Marketplaces > Sync now로 즉시 반영할 수 있습니다.
